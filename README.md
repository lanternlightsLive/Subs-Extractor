In the repository, open `logs/`, select Add file → Upload files, upload your `.log` or `.txt` Twitch chat logs, and commit.
Open Actions → Extract Twitch subscriptions → Run workflow (choose the default branch).
When the run succeeds, open the run summary and download the `twitch-subscription-reports` artifact from Artifacts.
Unzip the artifact to access the two CSV reports. Delete uploaded log files from the repository afterward if no longer needed

Download and install Chatty - https://chatty.github.io/ to log Twitch chat automatically during stream!
